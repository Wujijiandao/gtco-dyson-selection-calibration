# GitHub / Zenodo release policy

The historical release `v1.0.0-submission` and Zenodo DOI `10.5281/zenodo.21896997` remain immutable.

The present package is the RASTI-transfer working authority `v1.1.0-rasti-transfer`. It may replace/update the repository `main` branch. Do not force-move the historical tag.

After RASTI ScholarOne submission is finalized and the final transferred title/metadata have been verified, a new release may be created (recommended tag: `v1.1.0-rasti-submission`). If Zenodo integration is enabled, allow it to mint a new version DOI rather than modifying the old archived version.
